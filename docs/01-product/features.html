Features

What this is: the full feature inventory by priority, cross-checked against what is actually built. Most must-haves are already Working — the real news on this page is the gaps.

Status comes from the as-built code audit (out/04-asbuilt.md), not from the requirements docs. A feature can be a correctly-scoped must-have and still show Absent — that is not a contradiction, it is the actual state of the repo today.

The Groups gap

Do not silently drop this again. "Create and join groups of other users to interact with" is listed as a must-have in Forge Initial Requirements and reappears in stretch lists elsewhere in the notes. It does not exist in the code at all — no model, no collection, no UI.

Per the decision brief's reconciliation ruling (row 9), Groups moved to DEFERRED rather than being treated as done or forgotten. It is not required for the beta, but it is a real must-have from a formal requirements document that was never built — see decisions.html for the full ruling.
