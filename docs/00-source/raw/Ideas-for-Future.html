Ideas to Eventually Add Into The App and Make It Better

	•	Change architecture to light-weight frontend and an API-gateway to handle data fetching
	•	Things like the app would put in a request for events and get nothing other than the text and values for the events from the gateway. The gateway would handle getting the values and organizing them in a way that the frontend would understand. That way the data storage is completely abstracted from the frontend.
