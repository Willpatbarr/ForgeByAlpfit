Overview:
Goal is a class that will handle a user being able to create and track a goal. Users need to be able to create a goal for something such as ‘four workouts a week’. They need to be able to set a recurring set of day and times that they go and checkup on the goal saying that they are still on track. Hopefully completing that checkup fully every week. The user also needs to be able to set a frequency that the goal will reset checkups. For example if the user sets a goal for “6 workouts every 2 weeks”. They need to be able to set their reset frequency to every 2 weeks instead of 1. The user is going to be able to track these goals through a widget on the homescreen. The widget will show a short name and a ring that shows the amount of checkups in the reset window and which checkups were missed/completed. The user will also need to be able to edit all of this information on a goal.

Goal Requirements:
	•	Users will be able create goals
	•	Goals need to contain a start and end date
	•	Goals need to have a frequency
	•	Users will be able to check in on their goals
	•	Users will be able to see goal progress through the goals widget
	•	Users will be able to complete goal
	•	Users will be able to create a goal through the creation page 

Stretch Goal Requirements:
	•	Goals will be able to be checked-in through a notification on the user’s lock screen

Your Goal class seems to represent:

For these questions I will use the goal of “3 workouts per week” as an example goal
	•	1. The checkup would be a set amount of basically checkboxes to be marked during each reset period. In the case of the example goal; the checkup would be the user checking a box saying they worked out that day. Then at the reset period all the boxes or whatever is used to track would reset and the previous week’s results would be saved.
	•	2. I think count completed. If the user setup 3 checkups during the reset period then they would need to complete all three before the reset period is over. Eventually this can change but for now it’ll be like this.
