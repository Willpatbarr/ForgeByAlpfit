alright here comes the hard part. we need to update the way the widgets are built and displayed. Here is what we need: - we need a basic function that builds a basic feed widget. Similar to the current goal widget where it is the title and body.  - the function needs to take in the title, position, width, height, and body of the widget - we need another function that builds data driven widgets, this function being based off the basic widget function. - the data driven widget function needs to take in the name, position, width, height, and body of the widget. In this case the body we pass in needs to be able to be a function that describes what data the body pulls and how it is displayed. For example: the Next Workout widget will be a data driven workout. The ‘body’ will be a function that pulls the next workout event and knows how to display it in the body section of the widget. This allows widgets to be more easily built in the future. - We need the feed page to work off a grid system where the position of a widget is the top leftmost space of the grid the widget occupies, the width is how many spaces wide it is, and the height is how many spaces tall it is. This will allow us to easily move the widgets around and resize them.  So currently we need the feed page to be a 5x6 grid. 5 spaces horizontally (0-4) and 6 spaces vertically (0-5). Then here are the positions and sizes of the current widgets we have: - Next Workout: p = 0:0, h = 3, w = 4 - Goals: p = 0:2, h = 2, w = 4 - Friends: p = 4:0, h = 4, w = 1  Update Modules
