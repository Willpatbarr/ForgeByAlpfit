# Forge - Project Summary

## 🎯 Project Overview

**App Name**: Forge  
**Purpose**: A social fitness app designed to make gyms less intimidating by helping people start their fitness journey with friends and supportive communities.

**Core Problem**: There's a barrier of intimidation and self-consciousness that keeps people from starting a fitness journey. People are scared of looking dumb or don't know what to do, even though gym communities are generally very welcoming.

**Solution**: Connect users to each other and to the gym they work out at, creating a supportive network that makes fitness feel more approachable.

---

## 👥 Target Users

- **Primary**: Adults 18-late 50s (majority: younger adults who use social media)
- **Three main user types**:
  1. New gym attendees looking for help
  2. Consistent attendees looking to connect with others
  3. Gyms wanting to host/manage communities

**Stakeholder**: BYU-I Recreation Center (largest gym in Rexburg)

---

## 📱 Required Pages & Features

### 1. **Feed Page**
- View updates from gyms the user is part of
- View updates from friends
- View events happening that day

### 2. **Calendar Page**
- Change between calendar views (year, month, week, day)
- View events scheduled for different days
- Show which events came from where (gyms, friends, self)
- Filter which event sources are shown
- Start creating an event by clicking on a time of day
- View previews of event details by tapping
- Tap on events to edit them

### 3. **Event Creator Page**
- Choose between **Basic Event** or **Workout Event**

**Basic Events:**
- Invite friends to participate
- Set public or private view status
- If Gym: create event for all gym members to see
- Add dates and times
- Add notes

**Workout Events:**
- Invite friends to participate in workout
- Invite friends to edit workout
- Make workout public (all friends can view) or private (only invitees can view)
- Schedule date and time
- Schedule with which gym the workout will happen
- Add notes and exercises to be completed

### 4. **Social Page**
- Search for gyms and users
- Add friends (users) and join gyms
- View profile pages of users and gyms
- Message friends and gyms directly
- View community pages of Gyms and interact in posts
- Create and join groups of other users to interact with

**Gyms Only:**
- Create and manage community page and subpages
- Moderate interactions and posts from users
- Remove from or accept users into managed community

### 5. **Profile Page**
- Edit user preferences:
  - Name
  - Contact info (optional)
  - Profile Photo
- Manage friends list
- Manage joined gym communities

## 🏗️ Technical Stack

- **Framework**: Flutter/Dart
- **Backend**: Google Firebase (authentication, Firestore, cloud services)
- **IDE**: Visual Studio Code
- **Platform**: Mobile (iOS/Android), Desktop, Web (multi-platform deployment)
- **Authentication**: Firebase Auth
- **Database**: Cloud Firestore

---

## 🎨 Design Philosophy

- **Goal**: Make gym attendance less intimidating
- **Focus**: Community and social connections
- **Audience**: Accessible to all ages (18-50s+)
- **Style**: Clean, welcoming, approachable

---

## 🔑 Key Differentiators

1. **Dedicated to gym communities** - Not just workout planning, but community building
2. **Gym-hosted communities** - Gyms can manage their own spaces
3. **Friend-based workout planning** - Social aspect reduces intimidation
4. **Pre-visit connection** - Users can join gym communities before attending
